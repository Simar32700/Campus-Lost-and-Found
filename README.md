# Campus Lost and Found

  Campus Lost and Found is an AI-assisted web application for reporting, matching, and recovering lost items within a college campus.

  ## Problem

  Students and staff often lose items like ID cards, phones, books, wallets, and keys. Current methods such as WhatsApp groups and
  notice boards are slow, scattered, and unreliable.

  ## Solution

  The platform allows verified Thapar users to report lost and found items. An AI/NLP-based matching system compares item details
  such as description, category, color, location, and images. Admins verify matches, and users can communicate through real-time chat
  to return items safely.

  ## Key Features

  - Thapar email login verification
  - Lost and found item reporting
  - AI/NLP-based item matching
  - Image and OCR-based support
  - Admin approval system
  - Real-time notifications and chat
  - User and admin dashboards

  ## Tech Stack

  React.js, Node.js, Express.js, Firebase, Firestore, JWT, Socket.IO, NLP, OCR, Image Matching
